---
title: ¿Ques es Nano Stores
description: A guide in my new Starlight docs site.

---

Nano Stores es una biblioteca ligera de gestión de estado para aplicaciones JavaScript. Permite crear pequeños almacenes de estado independientes que pueden ser utilizados por diferentes partes de una aplicación sin necesidad de mantener todo el estado en un único lugar.

Está diseñada para funcionar con diferentes tecnologías frontend, como React, Vue, Svelte, Preact, Solid o JavaScript sin framework.
