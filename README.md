# 📚 Documentación No Oficial de Nano Stores

Una guía de desarrollador completa y accesible para **Nano Stores** — un gestor de estado minimalista y flexible para JavaScript.

> ⚠️ **Descargo de responsabilidad**: Esta es una documentación **no oficial** creada con fines educativos. Nano Stores es un proyecto de código abierto mantenido por sus respectivos colaboradores.

## 🎯 ¿Qué es Nano Stores?

Nano Stores es una biblioteca de gestión de estado ligera y agnóstica al framework que te permite:

- ✨ **Minimales**: Solo lo que necesitas, sin complejidad innecesaria
- 🔄 **Reactivos**: Sistema de suscripción eficiente para cambios de estado
- 🎛️ **Framework-agnóstico**: Úsalo con React, Vue, Svelte, Solid, o vanilla JavaScript
- 📦 **Pequeño tamaño**: Solo ~1KB en gzip
- ⚡ **Alto rendimiento**: Actualizaciones de estado optimizadas

## 📋 Requisitos

- Node.js 12.0+
- Un gestor de paquetes (npm, pnpm o yarn)

## 🛠️ Desarrollo Local

Para ejecutar la documentación localmente:

```bash
# Instala las dependencias
pnpm install

# Inicia el servidor de desarrollo
pnpm run dev

# Compilar para producción
pnpm run build
```
